PsyNeuView

Visual editor for PsyNeuLink computational models

Download for macOS

Requires macOS 14 (Sonoma) or later

  1. Download and open the DMG file
  2. Drag PsyNeuView to your Applications folder
  3. Launch PsyNeuView — the setup wizard handles the rest

First launch note

macOS may warn about an unidentified developer on first launch.
Right-click the app, click Open, then click Open again.
